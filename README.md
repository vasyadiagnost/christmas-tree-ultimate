# christmas tree ultimate

[English README](README.en.md)

Новогодние украшения для рабочего стола Windows на основе Snowhush 0.13.1.
Текущая версия Windows для Intel и AMD x64 — **0.2.3**.

Гирлянды подсвечивают три стороны каждого монитора. Рисованную ёлку можно
перетащить, изменить её размер и перенести на другой экран. Санта проезжает
в санях с двумя оленями, а трактор расчищает накопившийся внизу снег. Оба
проезжают за ёлкой. Проезды сопровождают тихие бубенцы и звук снегоуборщика.

- Гирлянды поддерживают постоянное свечение, мерцание и бегущую волну.
- Ёлка и гирлянды работают независимо от снегопада. Их можно скрыть поверх
  полноэкранных игр и видео.
- Снегоуборщик выезжает по заданному порогу снега. Интервал проездов Санты
  регулируется. Есть кнопки для ручного запуска обоих проездов.
- Звуки можно выключать вместе или по отдельности и регулировать их громкость.
  В 0.2.2 короткая пауза на стыке записи бубенцов убрана.
- Язык интерфейса можно переключить через меню трея: «Настройки → Язык →
  Русский / English». Выбор применяется сразу и сохраняется для следующих
  запусков, в том числе при входе в Windows.

## Установка

В разделе **Releases** скачайте установщик для Windows 10/11 x64 или ZIP с
установщиком и инструкцией. Откройте установщик и нажмите «Установить».
Он проверит компоненты Windows и при необходимости запустит встроенный
пакет Microsoft Visual C++ x64. Установка работает без интернета.
Windows может запросить права администратора для пакета Microsoft.

Программа появится в меню «Пуск» и будет запускаться при входе в Windows.
Автозапуск можно отключить через «Настройки → Открывать при входе» в меню
значка приложения рядом с часами. Там же находится раздел «Новогодние
украшения». При первом запуске интерфейс русский. Английский можно выбрать
через «Настройки → Язык → English», без перезапуска приложения.

Аргумент `--english` по-прежнему включает английский только на один запуск
и не меняет сохранённый язык. Для такого запуска сначала завершите уже
работающую копию через меню трея.

Переносимая сборка использует установленный в Windows Visual C++ x64.
Она запускается без установки приложения и сама не включает автозапуск.

## Сборка

Инструкции по подготовке аудио и сборке под Windows находятся в
[RELEASING.md](RELEASING.md). Все функции рабочего стола этой версии собраны
для Windows. Код Snowhush для macOS, Linux и сайта сохранён для работы с
исходным проектом.
